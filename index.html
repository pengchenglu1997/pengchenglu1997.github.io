About

Best-seller lists, library records and reading communities like BookTok all record what readers pay attention to. Language models learn from these records, and they now judge books whenever someone asks what to read next. My research measures which of these signals a model can read and carry, and which are lost.

I treat measurement as the hard part. I preregister confirmatory studies, run equivalence tests before calling a result null, and check how a record was built before I trust it.
